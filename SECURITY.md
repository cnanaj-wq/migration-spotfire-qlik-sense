# Sécurité

## Signaler un problème

N'ouvre pas d'issue publique pour une faille ou un secret exposé. Utilise le signalement privé de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability**.

## Périmètre

Ce dépôt est une expérimentation personnelle et n'est pas un service en production. Il ne contient ni identifiant ni donnée personnelle : la société, les clients et les utilisateurs de la table `securite` sont fictifs, et leurs adresses utilisent le domaine réservé `orvane.example`. Si tu trouves une donnée réelle, c'est une erreur à signaler.
